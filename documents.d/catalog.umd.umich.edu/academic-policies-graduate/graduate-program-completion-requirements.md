# Graduate Program Completion Requirements

## **Graduation/Application for Diploma**

Each candidate for a degree must file a Graduation Application with the Office
of the Registrar, typically within ten days of the beginning date of classes
for the term in which the student expects to complete the requirements for
degree. Please consult the [Applying to Graduate
Webpage](https://umdearborn.edu/one-stop/registration-and-degree-
planning/graduation-and-commencement/apply-graduate) for specific dates. If an
application for a diploma was filed for a previous graduation period in which
the student did not graduate, a new application is necessary. Degrees are
granted at the end of the fall, winter, and summer terms, even though
commencement exercises are held only in April (or May) and December.
